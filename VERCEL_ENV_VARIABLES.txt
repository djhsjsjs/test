DEALCHECK — Vercel Environment Variables

Add these in Vercel → Project → Settings → Environment Variables.

OPENAI_API_KEY
Your OpenAI API key (sk-...).

OPENAI_MODEL
gpt-5.4 (or another API model ID actually enabled in your OpenAI API project).

STRIPE_SECRET_KEY
Your Stripe secret key (sk_test_... while testing).

STRIPE_WEBHOOK_SECRET
The whsec_... signing secret for https://YOUR-VERCEL-DOMAIN/api/webhook.

STRIPE_PRICE_ID
The recurring Stripe Price ID for DEALCHECK Premium at $35 USD/month.
IMPORTANT: replace the old price ID with the new $35/month price ID.

DEALCHECK_STRIPE_PK
Your Stripe publishable key (pk_test_... while testing).

SITE_URL
https://YOUR-VERCEL-DOMAIN.vercel.app

NEXT_PUBLIC_SITE_URL
https://YOUR-VERCEL-DOMAIN.vercel.app

Payment model in this version
• $0.99 one-time starter charge today
• 3-day Premium trial
• $35/month recurring after the trial
• Payment method is collected during checkout for future recurring billing
• Stripe Checkout dynamically shows eligible methods for the customer and subscription
• Cards, Apple Pay, Google Pay and Link are supported when eligible; Stripe may show other locally supported methods when they are compatible with the currency/subscription.

Do not put secret keys into GitHub.
