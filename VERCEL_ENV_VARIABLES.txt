DEALCHECK — Vercel Environment Variables

Add these in:
Vercel → Project → Settings → Environment Variables

1. OPENAI_API_KEY
Value: your OpenAI API key (starts with sk-)
Environment: Production + Preview

2. OPENAI_MODEL
Value: gpt-5.4
You may change this only to an API model ID that is actually enabled in your OpenAI API project.
If blank or REPLACE_ME, the code automatically falls back to gpt-5.4.

3. STRIPE_SECRET_KEY
Value: your Stripe secret key (sk_test_... while testing)

4. STRIPE_WEBHOOK_SECRET
Value: the whsec_... signing secret from the Stripe webhook endpoint for:
https://YOUR-VERCEL-DOMAIN/api/webhook

5. STRIPE_PRICE_ID
Value: the Stripe recurring Price ID for DEALCHECK Premium at $2.99/month.
This is NOT the old $30/week price.

6. DEALCHECK_STRIPE_PK
Value: your Stripe publishable key (pk_test_... while testing)

7. SITE_URL
Value: https://YOUR-VERCEL-DOMAIN.vercel.app

8. NEXT_PUBLIC_SITE_URL
Value: https://YOUR-VERCEL-DOMAIN.vercel.app

SEARCH_API_KEY is not required by the current analyzer.
Do not put secret keys into GitHub.
